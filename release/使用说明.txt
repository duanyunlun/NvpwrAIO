================================================================
  NV显卡功耗软解  ——  使用说明
================================================================

一个把笔记本 NVIDIA 显卡功耗上限解锁到出厂值以上的工具。
本程序是集成品：功耗写入用的是 Nvpwr 驱动，签名绕过用的是 EfiGuard，
电压调整交给随包的 mVolt+。


----------------------------------------------------------------
一、它能做什么
----------------------------------------------------------------

· 把显卡功耗上限从出厂值（本机 175 W）提到更高，最高 350 W
· 调整核心电压 / XBAR 电压偏移
· 调整核心 / 显存 / XBAR 频率偏移
· 设置保存在本地，装了服务后每次开机自动重放

功耗值写在 NVIDIA 驱动自己的内存里，所以关掉本程序、卸载驱动都不影响它，
重启才会失效。


----------------------------------------------------------------
二、硬性前提（不满足就用不了）
----------------------------------------------------------------

1. NVIDIA 驱动程序必须是 616.92

   内核驱动按这个版本的内部布局读写功耗策略，版本不符时偏移会错位，
   所以只支持这一个版本。程序顶部会显示当前驱动版本：
     绿色 = 匹配，可用
     红色 = 不匹配，请先换成 616.92

2. Secure Boot 必须关闭

   需要在 BIOS 里关闭。开启时 Windows 会锁住驱动签名相关的设置。

3. VBS（基于虚拟化的安全性）必须关闭

   VBS 运行时，安全内核会拦下内核内存写入，驱动加载不了。
   这一项在 Windows 安全中心里没有直接开关（「内存完整性」只是它的一个
   消费者），程序底部有检测项。

4. 必须从 EfiGuard 引导启动

   EfiGuard 在启动阶段修补内核，让程序可以临时关闭驱动签名强制。
   没有它，本程序的自签名驱动无法加载。

   注意：从 EfiGuard 引导后，Windows 会自动禁用 VBS —— 这是正常现象，
   也是本程序需要的状态。


----------------------------------------------------------------
三、首次安装步骤
----------------------------------------------------------------

第 1 步：关闭 Secure Boot
  重启进 BIOS → Security → Secure Boot → Disabled → 保存退出

第 2 步：安装 EfiGuard 引导

  1) 在磁盘管理里，从现有分区腾出约 50 MB
  2) 新建一个 FAT32 分区，卷标设为 EFIGUARD（本机做成了 Z: 盘）
  3) 把本目录下的这两个文件复制进去：
         bootx64.efi       →  X:\EFI\BOOT\BOOTX64.EFI
         EfiGuardDxe.efi   →  X:\EFI\BOOT\EfiGuardDxe.efi
     （X: 是那个 EFIGUARD 分区）
  4) 重启一次，让固件发现这个分区
  5) 再次重启进 BIOS → 找到启动顺序 → 把名为「UEFI OS」的启动项
     调到第一位 → 保存退出

  说明：
  · 「UEFI OS」是固件自己起的通用名字，不是「EfiGuard」，这是正常的
  · 这一步无法由程序完成 —— 启动顺序存在主板固件里，Windows 禁止程序读写
    固件变量（实测错误码 1314）。bcdedit 的修改会被固件在启动时覆盖

第 3 步：关闭 VBS
  运行 NvpwrControl.exe（需要管理员权限，会自动请求）
  看底部「虚拟化安全」：
    · 显示「已开启」（红色）→ 点一下，重启
    · 显示「已关闭」（绿色）→ 已经好了

第 4 步：确认前提条件
  程序底部五个标签应该都是绿色：
    ✓ Secure Boot：已关闭
    ✓ EfiGuard：已生效
    ✓ 虚拟化安全：已关闭
    ✓ 驱动阻止列表：已关闭
    ✓ CI 策略：已清除

  红色的点一下即可（EfiGuard 和 Secure Boot 两项不可点击，
  分别需要在 BIOS 里和启动顺序里处理，鼠标悬停有说明）。

第 5 步：安装服务（可选，但建议）
  点右下角「安装服务」。装好后每次开机自动重放设置，
  不用每次手动开程序点一遍。
  服务只是帮你"开机自动点一下应用"，不会让内核驱动常驻。


----------------------------------------------------------------
四、日常使用
----------------------------------------------------------------

改功耗：
  在「功耗」卡片里用 +/− 调到想要的瓦数 → 点「应用」
  首次应用会自动关闭驱动签名强制、加载驱动、下发、再恢复签名强制，
  整个过程几秒，只有加载驱动的那一瞬间签名强制是关闭的。

关掉程序：
  直接关窗口即可。程序退出时会卸载内核驱动，系统里不留未签名驱动。
  功耗值不受影响，会一直保持到重启。

调整电压 / 频率：
  电压卡片和频率卡片各自有「应用」按钮，独立生效。


----------------------------------------------------------------
五、注意事项
----------------------------------------------------------------

★★ 杀毒软件会删掉 bootx64.efi ★★

  Windows Defender 把 EfiGuard 的引导器识别为
      HackTool:Win64/EfiGuard.A
  实测：扫描包含该文件的目录会报 1 个威胁，就是这个文件。
  （本程序的其他文件、以及 Nvpwr 驱动，都不被检出。）

  如果被杀软删掉，EfiGuard 就无法启动，本程序也就用不了。
  建议给那个分区加排除项：
      Windows 安全中心 → 病毒和威胁防护 → 管理设置 →
      排除项 → 添加排除项 → 文件夹 → 选择 EFIGUARD 分区

  注意：Nvpwr 驱动是以 Nvpwr.cer 自签名证书签的，属测试签名，
  不是正式的 WHQL 签名。

★ VBS 和 EfiGuard 是互斥的

  实测（本机 8 次启动，无例外）：
    · EfiGuard 生效时 → VBS 每次都被禁用
    · EfiGuard 未生效时 → VBS 每次都能启用
  而且从 EfiGuard 引导时，手动把注册表写成开启，重启后会变回关闭。

  所以「虚拟化安全」这一项只在它开启时可点击（点击 = 关闭）。
  已经关闭时不可点击 —— 开回来也会被 EfiGuard 关掉。

  想彻底恢复 VBS，只能不经过 EfiGuard 启动（代价是固件会移除
  EfiGuard 启动项，之后要进 BIOS 重新添加）。

★ 功耗上限重启失效

  这是显卡驱动的性质，不是程序的问题。装了服务后会自动重放。

★ 内核驱动在程序关闭后仍然保留

  这是为了让"改功耗"这件事不需要重置显卡设备（见下面一节）。

    · 程序运行期间加载一次内核驱动，之后一直保留
    · 关闭程序不会卸载它，功耗值也不会丢
    · 重新打开程序 → 驱动已就绪 → 直接改，立刻生效，不黑屏

  ★ 反作弊看的是 DSE，不是这个驱动：
    · 驱动签名强制（DSE）只在"加载驱动的那一瞬间"关闭，几秒内恢复，
      不是整个使用期间都关着
    · 不写 BCD、不开测试签名模式、桌面无水印
    · 需要完全干净的机器时，用设置里的【标准模式】（见下）

★ 什么时候需要重置显卡设备

  内核驱动加载时会记住"当时的功耗墙"作为出厂基线。如果功耗墙已经被
  改过（比如现在是 250 W，出厂是 175 W），驱动无法判断它是不是出厂值，
  就会拒绝工作。这时程序会先重置一次显卡设备，把墙变回出厂值。

  正常情况下你遇不到它，因为驱动加载后一直保留。只有这几种情况会：

    · 重启电脑后，程序第一次改功耗时（此时服务通常会先加载好驱动，
      所以一般也不需要）
    · 手动卸载过驱动，或者用过【标准模式】之后

  重置显卡设备的表现：屏幕黑几秒、程序短暂无响应、已设的电压和频率
  会由程序自动补回。这是正常步骤，不是故障。

★ 关于反作弊游戏（重要）

  实测结论：只要你是【从 EfiGuard 引导】的，就过不了内核级反作弊。

  EfiGuard 在启动时修补了内核（PatchGuard 和驱动签名强制），这是比
  我们那个 28 KB 驱动显眼得多的特征。卸载我们的驱动并不能改变这一点。

  所以：

    · 想玩带内核反作弊的游戏（无畏契约 / 三角洲 / 战地等）
      → 用设置里的【标准模式】：它会恢复出厂设置、停止服务、移除内核
        驱动，然后重启
      → 而且必须从【Windows 启动项】引导，不要走 EfiGuard

    · 机器上可以准备两套启动方式（开机按 F11 选临时启动项）：
        UEFI OS              调显卡用（EfiGuard）
        Windows Boot Manager 玩游戏用（内核干净）

  本程序在"本程序运行之外"不留下任何东西：驱动已卸载、DSE 已恢复、
  不写 BCD 标志。剩下的只有 EfiGuard 那一次启动期修补。

★ 提高功耗会增加电气和热负荷

  电源适配器可能长期撑不住，散热也未必跟得上。
  建议每次只加一点，用烤机软件观察稳定性和温度。


----------------------------------------------------------------
六、常见问题
----------------------------------------------------------------

Q: 顶部驱动版本显示红色
A: 当前驱动不是 616.92。程序不会下发任何设置，请先换成该版本。

Q: EfiGuard 显示「未生效」
A: 本次启动没经过 EfiGuard。检查 BIOS 启动顺序里「UEFI OS」是否在第一位。

Q: EfiGuard 显示「未安装」
A: 没找到 EfiGuard 分区，或者分区里缺引导文件。按第三节第 2 步操作。

Q: 点「应用」报错说需要重启显卡设备
A: 功耗墙已被改过，内核驱动无法重新识别出厂基线。
   按提示重启显卡设备（程序会自动做），或者重启电脑。

Q: 右下角「无法打开 \\.\Nvpwr（驱动未加载）」
A: 正常状态 —— 驱动只在应用设置时加载，用完就卸载。

Q: 服务装了有什么用
A: 开机时自动把设置重放一遍，省得每次手动开程序点一下。
   它做的是和「应用」完全一样的事，只是自动的。
   （注意：服务不会让内核驱动常驻 —— 驱动只在程序运行期间存在，
   见第五节。）

七、目录内容
----------------------------------------------------------------

NvpwrControl.exe     主程序（界面）
NvpwrControl.dll     主程序依赖
NvpwrControl.pdb     调试符号（可删）
Nvpwr.sys            内核驱动（真正改功耗的）
Nvpwr.cer            驱动签名证书
NvpwrCtl.exe         命令行工具（调试用）
NvpwrSvc.exe         后台服务（开机重放设置）
EfiDSEFix.exe        驱动签名强制开关（EfiGuard 的组件，本仓库编译）
bootx64.efi          EfiGuard 引导器（复制到 EFIGUARD 分区）
EfiGuardDxe.efi       EfiGuard 驱动（复制到 EFIGUARD 分区）
mvolt+.exe           电压调整（第三方，随包附带）

流程说明.md           技术实现细节（开发者向，普通使用不必看）

八、声明
----------------------------------------------------------------

本程序不包含任何 NVIDIA 官方代码，通过未公开的 NVAPI 私有接口与
NVIDIA 驱动通信，并按显卡驱动的内部内存布局读写功耗策略。

这类操作不在 NVIDIA 的支持范围内。所有改动由使用者自行承担风险，
包括但不限于：硬件损坏、系统不稳定、驱动重置、数据丢失、以及
涉及反作弊的游戏账号问题。

本程序在启动瞬间会临时关闭驱动签名强制（约一秒），用完立即恢复，
不写 BCD 标志，不开启测试签名模式，桌面无水印。
